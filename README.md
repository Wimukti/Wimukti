### Wimukthi Indeewara

Senior software engineer. I build developer tools and product software in TypeScript, React,
Python and Go, and lately a lot of it with Claude Code.

**Now: [ReviewStage](https://github.com/Wimukti/reviewstage)** — an open-source pull-request
review assistant on Claude Code. It drafts the review from the real diff on the reviewer's own
Claude plan, stages every finding privately, and posts only what the reviewer picks, under their
own GitHub name. Nothing posts until you click. Desktop app plus a phone that pairs by QR code.

```bash
npx reviewstage
```
